# Gazette Drouot watcher

Отслеживает одну или несколько страниц рубрик (списков статей) на gazette-drouot.com и показывает уведомление Windows для каждой новой или обновлённой статьи — щёлкните уведомление, чтобы открыть её в браузере по умолчанию.

## Как это работает

- При каждом запуске первые `MAX_PAGES` страниц списка каждой настроенной рубрики полностью сканируются (не только до первой "известной" статьи — тесты показали, что пагинация сайта не всегда хронологична, поэтому ранняя остановка может незаметно пропустить настоящие новости).
- Каждая найденная статья сравнивается с сохранённым состоянием (`state/<rubrique-key>.json`) по числовому id **и** дате публикации. Новый id → уведомление. Известный id, но дата отличается от предыдущей → уведомление снова (статья, вероятно, была переопубликована/отредактирована). Статья без указанной даты уведомляется только один раз и больше никогда не проверяется.
- Первый запуск для рубрики просто молча записывает текущее содержимое как базовый уровень — без потока уведомлений о уже существующих статьях при установке.
- Если за один запуск в одной рубрике появляется больше `FLOOD_CAP` новых/обновлённых статей, только первые получают собственное уведомление — остальные объединяются в одно сводное уведомление "ещё N новых постов".

## Установка

- **VPN должен быть отключён** во время работы — Cloudflare принудительно показывает интерактивную проверку для IP-адресов VPN, которую автоматизация не может пройти. Обычный домашний IP проходит без проблем.
- Требуется установленный Microsoft Edge (использует системный Edge через `channel="msedge"` в Playwright, отдельная загрузка браузера не нужна).
- `pip install -r requirements.txt`

## Настройка

**`gazette_watcher/config.py` — единственный файл, который нужно редактировать** для всего: какие страницы отслеживать, как часто проверять, насколько глубоко сканировать, ограничения на уведомления, паузы между предупреждениями и т.д. — у каждого параметра есть поясняющий комментарий. После изменения там что-либо вступает в силу при следующем запуске, **кроме** `POLL_INTERVAL_MINUTES`, для которого также нужно один раз заново запустить `install_task.ps1`, чтобы обновить реальную задачу в Планировщике заданий Windows.

## Панель управления (GUI)

Окно рабочего стола для всего перечисленного ниже без прямого обращения к PowerShell или config.py: установка / включение / отключение / удаление запланированной задачи, а также панель настроек (со сбросом к настройкам по умолчанию на случай ошибки) вместо ручного редактирования файла конфигурации. Значок флага переключает язык интерфейса (английский, 中文, español, हिन्दी, العربية, português, русский, français, 日本語, немецкий — по умолчанию следует языку интерфейса Windows, иначе используется английский); значок солнца/луны переключает светлую/тёмную тему (по умолчанию следует теме Windows). Оба выбора сохраняются в `gui_prefs.json`.

**Если у вас есть только `.exe`:** дважды щёлкните `GazetteDrouotWatcherGUI.exe` — больше ничего устанавливать не нужно. Файл должен находиться прямо в этой папке проекта, рядом с `gazette_watcher/`, `install_task.ps1` и т. д.

**Запуск из исходного кода:** дважды щёлкните `gui.pyw` (Windows запускает файлы `.pyw` через `pythonw.exe`, без окна консоли), либо:
```
pythonw.exe gui.pyw
```

**Чтобы собрать `.exe` самостоятельно** (он исключён через gitignore — не хранится в исходниках, соберите заново или скачайте из Release):
```
pip install pyinstaller
python -m PyInstaller --onefile --windowed --name GazetteDrouotWatcherGUI --icon icon.ico gui.pyw
```
Затем скопируйте `dist/GazetteDrouotWatcherGUI.exe` в корень проекта (рядом с `gui.pyw`) и удалите оставшиеся `build/`, `dist/` и `*.spec`.

## Ручной запуск

```
python -m gazette_watcher.watcher
```

## Планирование

Запустите `install_task.ps1`, чтобы зарегистрировать задачу "GazetteDrouotWatcher" в Планировщике заданий, которая работает с интервалом, заданным в `config.py`, пока вы вошли в систему. Запускайте его в любое время повторно (например, после изменения `POLL_INTERVAL_MINUTES`), чтобы обновить уже зарегистрированную задачу.

```
powershell -ExecutionPolicy Bypass -File install_task.ps1
```

Запустить один раз немедленно для теста:
```
powershell -Command "Start-ScheduledTask -TaskName GazetteDrouotWatcher"
```

Удалить с помощью `uninstall_task.ps1`:
```
powershell -ExecutionPolicy Bypass -File uninstall_task.ps1
```

## Если что-то пошло не так

Существуют два отдельных предупреждающих уведомления, каждое ограничено не чаще одного раза за `ALERT_COOLDOWN_HOURS` (config.py), чтобы длительная проблема не засыпала уведомлениями при каждом запуске:

- **"blocked by Cloudflare"** — защита сайта от ботов перехватила запрос. Почти всегда решается отключением VPN.
- **"needs an update"** — страница загрузилась нормально, но её HTML больше не соответствует тому, что ожидает этот скрипт. Скорее всего, gazette-drouot.com изменил разметку страниц, и селекторы в скрапере (`gazette_watcher/scraper.py`) нужно обновить соответственно.

В `logs/watcher.log` есть полная информация о каждом запуске — проверьте его в первую очередь, если уведомления перестали появляться.

## Тестирование без обращения к настоящему сайту

В `test/` есть небольшая среда с локальным фейковым сайтом для тестирования логики скрапинга/уведомлений в изоляции, без нагрузки на настоящий сайт и без зависимости от его текущего содержимого. См. `test/README.md`.

## Добавление ещё одной страницы для отслеживания

Добавьте ещё одну запись в `RUBRIQUES` в `config.py` — пока страница использует ту же структуру карточек `div.articleResume`, больше ничего менять не нужно.
