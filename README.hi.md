# Gazette Drouot watcher

gazette-drouot.com के एक या अधिक रुब्रीक (लेख सूची) पेजों पर नज़र रखता है और हर नए या अपडेट किए गए लेख के लिए एक Windows सूचना दिखाता है — सूचना पर क्लिक करके उसे अपने डिफ़ॉल्ट ब्राउज़र में खोलें।

## यह कैसे काम करता है

- हर रन में, हर कॉन्फ़िगर की गई रुब्रीक के पहले `MAX_PAGES` लिस्टिंग पेज पूरी तरह से स्कैन किए जाते हैं (केवल तब तक नहीं जब तक कोई "ज्ञात" लेख न मिल जाए — परीक्षण से पता चला कि साइट का पेजिनेशन भरोसेमंद रूप से कालानुक्रमिक नहीं है, इसलिए जल्दी रुकने से असली नई खबरें चुपचाप छूट सकती हैं)।
- मिला हर लेख उसके संख्यात्मक id **और** प्रकाशन तिथि दोनों के आधार पर सहेजी गई स्थिति (`state/<rubrique-key>.json`, जो `%LOCALAPPDATA%\GazetteDrouotWatcher\` के अंतर्गत है) से तुलना किया जाता है। नया id → सूचना। ज्ञात id लेकिन पिछली बार से अलग तिथि → फिर से सूचना (लेख संभवतः फिर से प्रकाशित/संपादित किया गया है)। बिना तिथि दिखाए लेख के लिए केवल एक बार सूचना दी जाती है, फिर कभी दोबारा जाँच नहीं होती।
- किसी रुब्रीक के पहले रन में केवल वर्तमान में मौजूद सामग्री को आधार रेखा के रूप में चुपचाप दर्ज कर लिया जाता है — इंस्टॉल करते समय पहले से मौजूद लेखों के लिए सूचनाओं की बाढ़ नहीं आती।
- यदि एक ही रन में किसी रुब्रीक में `FLOOD_CAP` से अधिक नए/अपडेट किए गए लेख मिलते हैं, तो केवल पहले कुछ को ही अपनी अलग सूचना मिलती है — बाकी को एक "N और नई पोस्ट" सारांश सूचना में मिला दिया जाता है।

## सेटअप

- इसके चलने के दौरान **VPN बंद होना चाहिए** — Cloudflare VPN IP पर एक इंटरैक्टिव चुनौती लागू करता है जिसे स्वचालन हल नहीं कर सकता। एक सामान्य होम IP बिना किसी समस्या के पास हो जाता है।
- Microsoft Edge इंस्टॉल होना आवश्यक है (Playwright के `channel="msedge"` के माध्यम से आपके सिस्टम के Edge का सीधे उपयोग करता है, अलग से ब्राउज़र डाउनलोड करने की आवश्यकता नहीं)।
- `pip install -r requirements.txt`

## कॉन्फ़िगरेशन

**हर चीज़ के लिए संपादित करने वाली एकमात्र फ़ाइल `config.py` है**: कौन से पेज देखने हैं, कितनी बार जाँच करनी है, कितनी गहराई तक स्कैन करना है, सूचना सीमाएँ, चेतावनी कूलडाउन, आदि — हर सेटिंग के साथ समझाने वाली एक टिप्पणी है (या इन्हें नियंत्रण पैनल के सेटिंग्स टैब से संपादित करें, नीचे देखें)। यह `%LOCALAPPDATA%\GazetteDrouotWatcher\config.py` में रहती है (पहली रन पर वहाँ अपने आप बन जाती है — `.exe` के बगल में नहीं), इसलिए `.exe` को स्थानांतरित करने या बदलने पर भी यह बनी रहती है। वहाँ कुछ भी बदलने के बाद, परिवर्तन अगली रन में प्रभावी होता है, **सिवाय** `POLL_INTERVAL_MINUTES` के, जिसके लिए नए अंतराल के साथ वास्तविक Windows टास्क शेड्यूलर कार्य को अपडेट करने हेतु नियंत्रण पैनल में फिर से **इंस्टॉल करें** पर क्लिक करना ज़रूरी है।

## नियंत्रण पैनल (GUI)

**यही ऐप है** — एक ही, स्वतंत्र `.exe`, जिसे चलाने वाली मशीन पर अलग से Python इंस्टॉल या स्क्रिप्ट फ़ाइलों की ज़रूरत नहीं। नीचे दी गई सभी चीज़ों के लिए एक डेस्कटॉप विंडो: अनुसूचित कार्य को इंस्टॉल / सक्षम / अक्षम / अनइंस्टॉल करना (सीधे नेटिव टास्क शेड्यूलर API के माध्यम से, कोई PowerShell नहीं), और कॉन्फ़िगरेशन फ़ाइल को हाथ से संपादित करने के बजाय एक सेटिंग्स पैनल (कुछ गड़बड़ होने पर "डिफ़ॉल्ट पर रीसेट करें" के साथ)। ध्वज आइकन इंटरफ़ेस भाषा बदलता है (अंग्रेज़ी, 中文, Español, हिन्दी, العربية, Português, Русский, Français, 日本語, जर्मन — डिफ़ॉल्ट रूप से आपकी Windows UI भाषा का अनुसरण करता है, समर्थित न होने पर अंग्रेज़ी पर वापस जाता है); सूरज/चाँद आइकन लाइट/डार्क के बीच स्विच करता है (डिफ़ॉल्ट रूप से आपकी Windows थीम का अनुसरण करता है)। दोनों विकल्प `%LOCALAPPDATA%\GazetteDrouotWatcher\gui_prefs.json` में सहेजे रहते हैं।

**यदि आपके पास केवल `.exe` है:** `GazetteDrouotWatcher.exe` पर डबल-क्लिक करें — इंस्टॉल करने के लिए और कुछ नहीं, और इसके साथ किसी और चीज़ की ज़रूरत नहीं। यह पूरी तरह स्वतंत्र है: `config.py`, `gui_prefs.json`, `state/`, और `logs/` — ये सभी पहली रन पर `%LOCALAPPDATA%\GazetteDrouotWatcher\` के अंतर्गत बनते हैं, `.exe` के बगल में नहीं, इसलिए यह जिस भी फ़ोल्डर से चलाया जाए, वहाँ फ़ाइलें कभी नहीं बिखेरता। अनुसूचित कार्य पंजीकृत करने के लिए विंडो में **इंस्टॉल करें** पर क्लिक करें — उसके बाद यह `config.py` में सेट किए गए अंतराल पर पृष्ठभूमि में अपने आप जाँच करता रहता है, इस विंडो (या ऐप) को खुला रखने की ज़रूरत नहीं, और हर PC पुनरारंभ के बाद यह स्वयं फिर से शुरू हो जाता है।

**इसके बजाय सोर्स से चलाना:** `main.pyw` पर डबल-क्लिक करें (Windows `.pyw` फ़ाइलों को `pythonw.exe` के माध्यम से चलाता है, कोई कंसोल विंडो नहीं दिखती), या:
```
pythonw.exe main.pyw
```

**`.exe` को स्वयं बनाने के लिए** (यह gitignore में है — सोर्स में कमिट नहीं किया गया, इसे फिर से बनाएँ या किसी Release से प्राप्त करें):
```
pip install pyinstaller
python -m PyInstaller --onefile --windowed --name GazetteDrouotWatcher --icon icon.ico main.pyw
```
फिर `dist/GazetteDrouotWatcher.exe` को प्रोजेक्ट रूट में (`main.pyw` के साथ) कॉपी करें और बचे हुए `build/`, `dist/`, और `*.spec` को हटा दें।

## मैनुअल रन

`main.pyw --watch` (या समकक्ष `GazetteDrouotWatcher.exe --watch`) वही है जिसे अनुसूचित कार्य वास्तव में कॉल करता है — एक जाँच चलाता है और बाहर निकल जाता है, कोई GUI नहीं। यह इसके बराबर भी है:
```
python -m gazette_watcher.watcher
```

## अगर कुछ गलत हो जाए

दो अलग-अलग चेतावनी सूचनाएँ मौजूद हैं, हर एक `ALERT_COOLDOWN_HOURS` (config.py) में अधिकतम एक बार तक सीमित है ताकि कोई लगातार बनी समस्या हर रन में सूचना से न भर दे:

- **"blocked by Cloudflare"** — साइट के बॉट-सुरक्षा ने अनुरोध को रोक दिया। लगभग हमेशा VPN बंद करने से हल हो जाता है।
- **"needs an update"** — कोई पेज ठीक से लोड हुआ लेकिन उसका HTML अब इस स्क्रिप्ट की अपेक्षा से मेल नहीं खाता। सबसे संभावित कारण यह है कि gazette-drouot.com ने अपने पेज का लेआउट बदल दिया है, और स्क्रेपर के सेलेक्टर्स (`gazette_watcher/scraper.py`) को इससे मेल खाने के लिए अपडेट करने की आवश्यकता है।

`%LOCALAPPDATA%\GazetteDrouotWatcher\logs\watcher.log` में हर रन का पूरा विवरण होता है — यदि सूचनाएँ आना बंद हो जाएँ तो पहले यहीं देखें।
