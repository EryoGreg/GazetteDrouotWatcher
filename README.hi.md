# Gazette Drouot watcher

gazette-drouot.com के एक या अधिक रुब्रीक (लेख सूची) पेजों पर नज़र रखता है और हर नए या अपडेट किए गए लेख के लिए एक Windows सूचना दिखाता है — सूचना पर क्लिक करके उसे अपने डिफ़ॉल्ट ब्राउज़र में खोलें।

## यह कैसे काम करता है

- हर रन में, हर कॉन्फ़िगर की गई रुब्रीक के पहले `MAX_PAGES` लिस्टिंग पेज पूरी तरह से स्कैन किए जाते हैं (केवल तब तक नहीं जब तक कोई "ज्ञात" लेख न मिल जाए — परीक्षण से पता चला कि साइट का पेजिनेशन भरोसेमंद रूप से कालानुक्रमिक नहीं है, इसलिए जल्दी रुकने से असली नई खबरें चुपचाप छूट सकती हैं)।
- मिला हर लेख उसके संख्यात्मक id **और** प्रकाशन तिथि दोनों के आधार पर सहेजी गई स्थिति (`state/<rubrique-key>.json`) से तुलना किया जाता है। नया id → सूचना। ज्ञात id लेकिन पिछली बार से अलग तिथि → फिर से सूचना (लेख संभवतः फिर से प्रकाशित/संपादित किया गया है)। बिना तिथि दिखाए लेख के लिए केवल एक बार सूचना दी जाती है, फिर कभी दोबारा जाँच नहीं होती।
- किसी रुब्रीक के पहले रन में केवल वर्तमान में मौजूद सामग्री को आधार रेखा के रूप में चुपचाप दर्ज कर लिया जाता है — इंस्टॉल करते समय पहले से मौजूद लेखों के लिए सूचनाओं की बाढ़ नहीं आती।
- यदि एक ही रन में किसी रुब्रीक में `FLOOD_CAP` से अधिक नए/अपडेट किए गए लेख मिलते हैं, तो केवल पहले कुछ को ही अपनी अलग सूचना मिलती है — बाकी को एक "N और नई पोस्ट" सारांश सूचना में मिला दिया जाता है।

## सेटअप

- इसके चलने के दौरान **VPN बंद होना चाहिए** — Cloudflare VPN IP पर एक इंटरैक्टिव चुनौती लागू करता है जिसे स्वचालन हल नहीं कर सकता। एक सामान्य होम IP बिना किसी समस्या के पास हो जाता है।
- Microsoft Edge इंस्टॉल होना आवश्यक है (Playwright के `channel="msedge"` के माध्यम से आपके सिस्टम के Edge का सीधे उपयोग करता है, अलग से ब्राउज़र डाउनलोड करने की आवश्यकता नहीं)।
- `pip install -r requirements.txt`

## कॉन्फ़िगरेशन

**हर चीज़ के लिए संपादित करने वाली एकमात्र फ़ाइल `gazette_watcher/config.py` है**: कौन से पेज देखने हैं, कितनी बार जाँच करनी है, कितनी गहराई तक स्कैन करना है, सूचना सीमाएँ, चेतावनी कूलडाउन, आदि — हर सेटिंग के साथ समझाने वाली एक टिप्पणी है। वहाँ कुछ भी बदलने के बाद, परिवर्तन अगली रन में प्रभावी होता है, **सिवाय** `POLL_INTERVAL_MINUTES` के, जिसके लिए वास्तविक Windows टास्क शेड्यूलर कार्य को अपडेट करने हेतु `install_task.ps1` को भी एक बार फिर से चलाना ज़रूरी है।

## नियंत्रण पैनल (GUI)

PowerShell या config.py को सीधे छुए बिना नीचे दी गई सभी चीज़ों के लिए एक डेस्कटॉप विंडो: अनुसूचित कार्य को इंस्टॉल / सक्षम / अक्षम / अनइंस्टॉल करना, और कॉन्फ़िगरेशन फ़ाइल को हाथ से संपादित करने के बजाय एक सेटिंग्स पैनल (कुछ गड़बड़ होने पर "डिफ़ॉल्ट पर रीसेट करें" के साथ)। ध्वज आइकन इंटरफ़ेस भाषा बदलता है (अंग्रेज़ी, 中文, Español, हिन्दी, العربية, Português, Русский, Français, 日本語, जर्मन — डिफ़ॉल्ट रूप से आपकी Windows UI भाषा का अनुसरण करता है, समर्थित न होने पर अंग्रेज़ी पर वापस जाता है); सूरज/चाँद आइकन लाइट/डार्क के बीच स्विच करता है (डिफ़ॉल्ट रूप से आपकी Windows थीम का अनुसरण करता है)। दोनों विकल्प `gui_prefs.json` में सहेजे रहते हैं।

**यदि आपके पास केवल `.exe` है:** `GazetteDrouotWatcherGUI.exe` पर डबल-क्लिक करें — इंस्टॉल करने के लिए और कुछ नहीं। इसे सीधे इस प्रोजेक्ट फ़ोल्डर में, `gazette_watcher/`, `install_task.ps1` आदि के साथ होना चाहिए।

**इसके बजाय सोर्स से चलाना:** `gui.pyw` पर डबल-क्लिक करें (Windows `.pyw` फ़ाइलों को `pythonw.exe` के माध्यम से चलाता है, कोई कंसोल विंडो नहीं दिखती), या:
```
pythonw.exe gui.pyw
```

**`.exe` को स्वयं बनाने के लिए** (यह gitignore में है — सोर्स में कमिट नहीं किया गया, इसे फिर से बनाएँ या किसी Release से प्राप्त करें):
```
pip install pyinstaller
python -m PyInstaller --onefile --windowed --name GazetteDrouotWatcherGUI --icon icon.ico gui.pyw
```
फिर `dist/GazetteDrouotWatcherGUI.exe` को प्रोजेक्ट रूट में (`gui.pyw` के साथ) कॉपी करें और बचे हुए `build/`, `dist/`, और `*.spec` को हटा दें।

## शेड्यूलिंग

टास्क शेड्यूलर में "GazetteDrouotWatcher" कार्य पंजीकृत करने के लिए `install_task.ps1` चलाएँ, जो `config.py` में सेट किए गए अंतराल पर चलता है, जब तक आप लॉग इन हैं। पहले से पंजीकृत कार्य को अपडेट करने के लिए इसे कभी भी फिर से चलाएँ (उदाहरण के लिए `POLL_INTERVAL_MINUTES` बदलने के बाद)।

```
powershell -ExecutionPolicy Bypass -File install_task.ps1
```

परीक्षण के लिए तुरंत एक बार चलाने के लिए:
```
powershell -Command "Start-ScheduledTask -TaskName GazetteDrouotWatcher"
```

`uninstall_task.ps1` के साथ इसे हटाएँ:
```
powershell -ExecutionPolicy Bypass -File uninstall_task.ps1
```

## अगर कुछ गलत हो जाए

दो अलग-अलग चेतावनी सूचनाएँ मौजूद हैं, हर एक `ALERT_COOLDOWN_HOURS` (config.py) में अधिकतम एक बार तक सीमित है ताकि कोई लगातार बनी समस्या हर रन में सूचना से न भर दे:

- **"blocked by Cloudflare"** — साइट के बॉट-सुरक्षा ने अनुरोध को रोक दिया। लगभग हमेशा VPN बंद करने से हल हो जाता है।
- **"needs an update"** — कोई पेज ठीक से लोड हुआ लेकिन उसका HTML अब इस स्क्रिप्ट की अपेक्षा से मेल नहीं खाता। सबसे संभावित कारण यह है कि gazette-drouot.com ने अपने पेज का लेआउट बदल दिया है, और स्क्रेपर के सेलेक्टर्स (`gazette_watcher/scraper.py`) को इससे मेल खाने के लिए अपडेट करने की आवश्यकता है।

`logs/watcher.log` में हर रन का पूरा विवरण होता है — यदि सूचनाएँ आना बंद हो जाएँ तो पहले यहीं देखें।
